### awk
& getline var`：同一命令字符串复用同一个 cmd /C 子进程（双向管道），`close()` 同时关闭读写两端并返回退出码，程序结束时统一回收；读入返回 1/0/-1，失败写 ERRNO。Windows 差异：与 GNU 一样原样写入 LF，但 cmd.exe 的原生过滤器（more、find 等）在重定向管道下只把 CRLF 视为完整行，LF-only 输入会缓冲到 EOF，“先写后读”的交互需改用 `printf "...\r\n"` 或选择不依赖行缓冲的命令；cmd 不做行编辑/回显，命令分隔符是 `&` 而不是 `;`，sh 与 cmd 的其它语法差异仍适用。FNR/NR、空文件重置与主输入 getline 行为已用本机 gawk 5.4.0 实测对照。输入按需打开：文件轮到它时才打开，缺失文件的报错出现在处理前序文件之后（上一轮的一次性预加载会提前报错），报错后继续处理后续文件并退出 1；主输入与 `getline < file` 都按记录流式读取，内存不随输入大小增长，`close(file)` 之前复用同一文件句柄。仍不支持：多字符 RS、ENDFILE 伪规则；BEGIN 阶段的 getline 不读取主输入（记录在 BEGIN 之后才载入，gawk 会读第一条）。

### bc
i128 整数运算，/ 与 % 向零截断（GNU scale=0 默认语义）；支持 + - * / % ^ ( )、变量赋值、; 分隔、# 注释与 quit。无任意精度、scale、ibase/obase 与函数——遇到不支持结构时打印提示并跳过该行。banner 为 bc 0.1.0 (RuxCmd)。

### cksum
仅 POSIX CRC32（-a crc）。-z/--zero 以 NUL 终止输出，隐式 stdin 不带文件名，显式 - 打印 -；读取错误报错。本机 GNU cksum 8.32 无 --zero，仅该差分用例跳过；NUL CRC 有已知向量行为测试。不支持其他算法和校验清单。

### column
-t 模式未给 -s 时连续空白折叠为单一分隔符；显式 -s 按字符切分不折叠。默认 fill 模式未实现。

### comm
支持 -z NUL 记录及原始字节比较；-1/-2/-3 隐藏列后压缩剩余列的 TAB 前缀。要求两个文件操作数，输入已按相同字节顺序排序；不支持 stdin 操作数、GNU 排序校验诊断和 --total。

### cp
默认覆盖已存在的可写目标（对齐 GNU）；`-n` 静默跳过并退出 0；`-n` 与 `-i` 以最后出现者为准，`-f` 为独立开关（`-n` 恒压过 `-f`）。覆盖只读目标必须带 `-f`：无 `-f` 时即使 `-i` 答 y 也报 "Permission denied" 退出 1；`-i` 提示写 stderr；递归复制单条失败不中断其余条目，但整体退出 1。以 `.`/`..` 结尾的源将内容并入已存在的目标目录（目标不存在时报错）；多源时目标必须是已存在目录。残留差异：不支持 `-a`/`-u`/`-t`/`-T`/`-l`/`-b`，`-p` 仅实现可映射部分（只读属性 + 访问/修改时间；其余 POSIX mode 位与 owner/group 在 NTFS 无对应，不可映射），`cp src/. missing` 不创建目标目录（GNU 会创建）。

### cut
支持 -z NUL 记录；字节和字段选择保持原始数据，-c 对合法 UTF-8 记录按字符选择，非法输入回退为字节。NUL 模式保留 CR/LF，默认 LF 模式仍剥 CRLF。无字段分隔符的记录默认透传，-s 时抑制；本端既有 -s 也作用于 -b/-c（与 GNU 不同）。不支持 -n/--complement。

### dd
核心子集：if/of/bs/ibs/obs/count/skip/seek，支持 GNU 尺寸后缀（c/w/b/K/KB/M/G 及 1000 进制形式）；conv 支持 notrunc 并拒绝其他值；stdout 不可 seek。GNU 的 records/copy 统计输出到 stderr。conv/flag 完整面（sync、fullblock、iflag）不支持。

### diff
退出码遵循 GNU（0/1/2）。普通格式输出未合并的 d/a 命令，行号锚点与 GNU 一致；c 合并与区间折叠未实现。

### du
默认按 1K 块报告实际分配（GetCompressedFileSize，稀疏文件按真实分配），`--apparent-size` 改用逻辑大小，`-b` 输出字节，`-h` 采用 GNU 记法（不足 10 个单位保留一位小数，`1.0K`/`4.9K`/`10K`）；硬链接每次调用只计一次且重复参数行省略；目录同样按身份去重（`du a ./a` 只输出一次）；不可读路径报错并退出 1；默认按后序为每个子目录各输出一行（空目录也输出 0），`-s` 仅输出操作数，`-c` 始终追加 total 行（单参数也输出）。残留差异：MSYS GNU du 按 4K 簇估算分配，在分配粒度等于逻辑大小的文件系统上块数会与之不同（apparent 模式一致）；不支持 `--max-depth`/`-a`/`-x`/`--exclude`。

### expr
/ &（GNU 左操作数语义）、比较（双方均为整数按数值否则按字符串）、: 与 match 的锚定 BRE 匹配（返回分组 1 或匹配长度）、substr/index/length。BRE 反向引用不支持（报语法错误）；退出码与 GNU 一致（0/1/2）。

### find
maxdepth 遵循 GNU（0=仅起点，1 含子项）；接受 GNU 单横线长选项（-name、-type 等）；未知 -type 值与遍历错误退出 1；非法 glob 不再 panic。新增并与本机 MSYS GNU find 实测对照：-print0 以 NUL 分隔记录；-delete 隐式开启 -depth，先删子项再删父项；-size [+-]N[cwbkMG] 默认 512 字节块并向上取整；-mtime 按 24 小时整日取整；-type l 依据 FILE_ATTRIBUTE_REPARSE_POINT 判定，junction 也算链接且遍历不跟随；-exec 支持 `{} \;`（每条一次）与 `{} +`（结束时一次批量调用，不按 ARG_MAX 分片）。新增：谓词与动作按命令行顺序求值并遵循 GNU 的隐式 -and 短路，-delete 可与 -print/-print0/-exec 任意组合（如 `-print -delete`、`-delete -name x`）。残留差异：junction 被 MSYS GNU find 报告为 -type d，本实现归为 -type l；输出使用反斜杠路径；不支持 -o/-a/! 与 -newer/-perm 等谓词，未知谓词报错退出 1。

### grep
字节安全读行：非 UTF-8 输入按 lossy 匹配并原样输出字节；单文件输出无前缀；-F 按字面匹配。新增并与本机 MSYS GNU grep 实测一致：--include/--exclude/--exclude-dir 按基名 glob 过滤（也过滤显式文件操作数）；-m 按文件计数，-m 0 不读取；-z 输入输出均以 NUL 为记录分隔（-l/-L 的文件名仍以换行结尾，与 GNU 相同）；-L 与 -l 谁后出现谁生效，退出码仍取决于是否匹配到行；全部输入被过滤时不输出 -c 计数。多文件 -c 与 GNU 一致逐文件输出 name:count（含 0 计数，GNU 无 total 行），-h 时逐文件裸计数，-l/-L 优先于 -c，-m 0 不读取且无输出。残留差异：未加 -r 的显式目录操作数 GNU 报错后仍输出 name:0，本实现只报错；文本模式下含 NUL 且无换行的文件，GNU -c 的计数与本实现不同（实测 2 vs 1）；glob 不支持 [abc] 字符类。

### head
支持 -z 记录计数，-c 仍按字节计数；选中数据、CR/LF 和未终止末记录原样输出，不补 NUL。多文件及 -v 标题仍以 LF 终止；-n 与 -c 互斥。GNU 负数行数语义仍不支持。

### install
复制文件；`-d` 建目录，`-D` 建目标父目录。八进制权限的写位映射 Windows 只读属性，不等价于 Unix 所有者、组和执行位。替换已有文件条目，不改写其硬链接别名；源与目标同一文件时报错。不支持符号权限及其他 GNU install 选项。

### iostat
覆盖 CPU 报告头部与行、百分比范围、count 多帧、已移除设备选项被拒绝；仅聚合 CPU 指标，未实现 GNU 的磁盘/设备报表与 interval 精度。

### md5sum
支持 -z/--zero 和 --tag -z，NUL 模式不转义文件名；-z -c 退出 1。普通校验从 stdin 或 - 读取清单，保留精确文件名，支持 GNU 转义/BOM/二进制标记/tag，并传播读取错误；FAILED 写 stdout，--status 静默。不支持 -b/-t、strict 或 NUL 清单解析。

### mkfifo
创建瞬时的 Windows 命名管道服务端句柄并立即关闭，不留下持久对象；-m 声明不支持。

### mktemp
使用系统安全随机源替换至少三个连续 X，独占创建避免覆盖。支持 `-d`、`-p DIR`、`-t` 和后缀。默认目录遵循 Windows 临时目录规则；继承 Windows ACL，不提供 Unix 0600/0700 权限语义。不支持无值 `--tmpdir` 和 dry-run。

### nslookup
A/AAAA/CNAME/MX/TXT 经真实查询解析（getaddrinfo / DnsQuery_W）；类型名大小写不敏感；不支持的类型报错退出 1。SERVER 位置参数已移除。

### sar
覆盖带时间戳的 CPU 报告、百分比范围、count 有界、内存报表与默认 CPU+内存输出；不支持 -d 磁盘报表与 -f 历史日志。

### sed
默认 POSIX BRE（-E/-r/--regexp-extended 切换 ERE，两种方言均带 GNU \+ \? 扩展）；地址与 s 命令共用方言；替换端支持 & 与 \1-\9、\n/\t/\r 以及 g/N/p/i 标志。模式中的反向引用不支持（启动报错）。非 UTF-8 数据按原始字节匹配并原样透传；行号逐文件重置；缺失的末行换行保留。 -f FILE 从文件读脚本。

### sha1sum
支持 -z/--zero 和 --tag -z，NUL 模式不转义文件名；-z -c 退出 1。普通校验支持 stdin、精确文件名、GNU 转义、BOM、二进制标记和 BSD tag；读取错误不产生部分数据的成功摘要。不支持 -b/-t、strict 或 NUL 清单解析。

### sha256sum
SHA-256，NUL 输出与普通清单校验规则同 sha1sum：-z 禁止文件名转义，-z -c 报错；支持 stdin 清单、精确文件名和读取错误传播。不支持 -b/-t、strict 或 NUL 清单解析。

### sha512sum
SHA-512，NUL 输出与普通清单校验规则同 sha1sum；不支持 -b/-t、strict 或 NUL 清单解析。

### touch
经 SetFileTime 更新已存在文件、目录与只读文件的 atime/mtime；-a 与 -m 选择更新的时间。-d/--date、-t、-r/--reference 未实现。

### truncate
尺寸支持 +/- 调整与 K/M/G/T/P/E（1024 进制）或 KB/MB/GB（1000 进制）后缀；+ 表示不小于。--io-blocks 不支持。

### traceroute
通过 IcmpSendEcho 发送 IPv4 ICMP 探测，超时单位为毫秒；到达目标、收到不可达状态或达到跳数上限时结束。不支持 IPv6、UDP/TCP 探测和反向 DNS。已测环回和有界 TEST-NET 场景，多路由器网络行为未验证。没有 `tracert` 可执行别名。

### uniq
支持 -z NUL 记录，-c/-d/-u/-i/-f 保留分组首条原始记录。跳过字段时以 space/TAB/LF 分界，剩余字节不归一化，CR 保留为内容；非法 UTF-8 记录不混同。有效 UTF-8 的 -i 保留 Unicode 小写规则；不支持输出文件操作数及其他分组扩展。

### users
枚举 WTS 会话用户名，按首次出现顺序去重；失败回退 USERNAME（或 unknown）。`-q/--count` 为扩展，与 GNU utmp 排序和重复会话输出不同；不支持 utmp FILE 操作数。

### xxd
已实现 GNU 兼容的 -c / -g（含 0=不分组）/ -l / -s（绝对、+N 相对、-N 从末尾；支持十进制与 0x）/ -u / -p / -i / -e / -b / -a / -n；各模式默认列数为 16、-i 12、-p 30、-b 6，默认分组 2（-e 为 4）。选项冲突（-p 与 -b/-e/-i、-e 与 -b/-i）按 GNU 报错；-i 的变量名默认由输入路径净化得到，`-n NAME` 可显式覆盖：两者都把非字母数字字节替换为 `_`，首位为数字时前缀 `__`，GNU 不校验、非法标识符也不报错；显式 `-n` 在 stdin 输入时仍输出声明与长度行，无 `-i` 时被忽略；-b 可与 -i 组合输出 0b 字面量。-a 只折叠按 `-c` 列宽判定的全零行：连续 ≥3 行输出首行与 `*`，输入结尾的零行按 GNU 规则保留最后一行（故 EOF 处恰好 3 行零时仍原样输出 3 行），不完整尾行不参与折叠；`-p`/`-i` 下 -a 被忽略，-b/-e 下同样生效，重复 -a 与 GNU 一样切回关闭。逆向 -r 只解析地址后的十六进制主体（ASCII 列不参与），支持地址空洞零填充、`*` 折叠行忽略、`-` 分组符、奇数半字节丢弃与 CRLF 输入；`-r -s` 仅接受非负绝对偏移。未实现：-C/-t 的 C 头定制、-o 偏移显示、-d 十进制地址、-E EBCDIC、-R 着色与 postscript（-ps）；-s 不接受 GNU 的尾随后缀（如 `16k` 在本实现中拒绝），多文件按顺序拼接（GNU 仅接受一个输入）。地址、十六进制、-a 折叠与 -n 命名输出已与本机 GNU xxd 2026-06-16 逐字节比对一致。

### zip
原生 Rust 实现（zip crate + deflate），不再依赖 PowerShell；支持递归、静默与指定输出名，目录条目带尾斜杠，不支持的其他 GNU zip 选项由 clap 报错退出 2。残留差异：条目输出没有 GNU 的 `(deflated NN%)` 百分比；归档每次重建（不追加更新已有归档）；时间戳与压缩细节不保证与 GNU zip 逐字节一致。
