# 文件筛选、批处理与校验

以下示例在 CMD 中执行，当前目录为 RuxCmd 的 bin 目录。先创建目标目录，再选择一种复制方式。

```bat
.\mkdir.exe -p "C:\backup\out"
.\find.exe "C:\data\源 文件" -type f -name "*.txt" -print0 | .\xargs.exe -0 -r .\cp.exe -t "C:\backup\out" --
```

等价的直接批处理形式：

```bat
.\find.exe "C:\data\源 文件" -type f -name "*.txt" -exec .\cp.exe -t "C:\backup\out" -- {} +
```

两者都会按命令行长度分批，支持中文、空格和命令元字符作为文件名内容；不会把输入文件名拼接成 shell 命令。示例会把文件复制到同一个目录，因此源目录中同名文件仍遵循 cp 的覆盖规则。需要保留目录结构时，应另行设计目标路径映射。

生成目标文件清单并在以后核验：

```bat
.\find.exe "C:\backup\out" -type f -print0 | .\xargs.exe -0 -r .\sha256sum.exe > "C:\backup\checksums.txt"
.\sha256sum.exe --check "C:\backup\checksums.txt"
```

清单位于被扫描目录之外。清单验证检查清单中的文件；它不检测后来新增但未列入清单的文件。复制后要证明与源内容相同，还需要对照源清单或逐文件摘要；项目的场景测试会执行这种源/目标对照。

## 输入与参数

- 文件路径流推荐 `-print0` 配合 `-0`，而不是普通换行文本；NUL 模式不解释引号和反斜杠，保留空参数及记录内 CR/LF。
- 普通 xargs 输入是 GNU 风格的引号/反斜杠语法，不是 Windows 路径语法或 shell 脚本。CR 也是内容，CRLF 不自动归一化；普通模式下未经引用的路径反斜杠会被当作转义。
- `-I STR`（以及 `-i`、`--replace[=STR]`）按非空逻辑记录替换初始参数内全部标记；输入不会被再次当模板解析。不带替换选项时 `{}` 是字面参数。
- `-r` 在空输入时不执行子命令。普通模式省略 -r 会执行一次，替换模式空输入不执行。未指定命令时输出内建 echo 行，不依赖外部 echo.exe。
- 命令操作数之后的选项属于子命令；如需结束 xargs 选项，可用 `--`。子命令不会自动经过 shell，内建命令或 shell 语法需显式调用 shell。
- 输入要求 UTF-8。非法字节、未闭合引号、结尾不完整转义和普通模式中的 NUL 都会报错，不能用有损替换悄悄改变文件路径。

CMD 的外部程序管道可用于以上字节流示例。在 PowerShell 中可让 `cmd /d /c` 执行整条示例管道；外层字符串仍需遵守 PowerShell 的引用规则。不要把 NUL 数据经 `Get-Content`、`Out-String` 或文本格式化再传递。本项目的场景测试直接连接原生进程 BaseStream，不依赖 PowerShell 文本管道的版本差异。

## 批次与错误

两个命令共用保守的 8000 UTF-16 单位预算，计入程序名、固定参数、参数引用、转义和终止 NUL。xargs 的 -n 是额外的条数上限，不能绕过长度限制。单项过长会明确失败，不截断路径；替换后命令也会重新计量。该预算不保证显式 shell 展开后的命令长度符合 shell 自己的限制。

find 的每个 `-exec … {} +` 动作独立分批，满批即执行，遍历结束刷新尾批；同一动作保持遍历顺序。子命令对文件树的修改可能影响后续遍历，不保证延迟到遍历结束。普通子失败累计到 find 的最终退出码 1，其他批次仍处理；固定命令超限只诊断一次，超长路径拒绝后继续合法路径。分号形式与原有表达式短路规则保持原行为。

xargs 普通子失败累计为 123 并继续；子状态 255 导致 124 并停止后续执行；无法执行/找不到程序为 126/127；自身输入、编码、用法和长度错误为 1。已经执行的批次不会回滚。子进程 stdin 接空设备，不能抢读 xargs 后续输入；-p 单独从控制台确认。

普通 shell 管道的末端状态不能完整代表每个阶段。可靠脚本还应检查筛选端与执行端是否都成功；场景测试会分别等待并检查两端，设置统一超时并回收所属进程。

## 开发验证

```powershell
pwsh -NoProfile -File scripts/tests/file-batch-tests.ps1 -BinDir target/x86_64-pc-windows-msvc/release
```

该检查创建临时 fixture，验证 81 个中文/空格/元字符名称、多批次复制、逐文件 SHA256 对照、校验清单、空选择及子失败传播，并在结束时清理。Verify 和 ZIP 解压验证自动调用它。GNU 差分、逐项 argv 回归和长度边界单测补充验证具体语义；这些检查不代表完整 GNU findutils 兼容。
